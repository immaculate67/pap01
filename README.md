# GeStock — PAP

Sistema de gestão para pequenos negócios, construído com PHP, MySQL, Bootstrap, JavaScript, HTML/CSS e VS Code.

## Stack
- Front-end: HTML + CSS + Bootstrap + JavaScript
- Back-end: PHP 8+
- Base de dados: MySQL / MariaDB
- Ambiente local recomendado: XAMPP

## Instalação rápida
1. Instala XAMPP e inicia Apache + MySQL.
2. Copia a pasta `gestock` para `C:\xampp\htdocs\gestock`.
3. Abre `http://localhost/phpmyadmin`.
4. Importa `database/gestock.sql`.
5. Abre `http://localhost/gestock/`.
6. Login demo: `admin` / `admin123`.
